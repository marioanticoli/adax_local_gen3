# Adax Gen 3 Local

Local Home Assistant integration for Adax Gen 3 Wi-Fi heaters.

## Features

- Local control over Wi-Fi
- Bluetooth LE provisioning
- Climate entity
- No cloud account required

## Installation

1. Open HACS.
2. Go to Integrations.
3. Open the three-dot menu and select Custom repositories.
4. Add `https://github.com/marioanticoli/adax_local_gen3`.
5. Select Integration as the category.
6. Install Adax Gen 3 Local.
7. Restart Home Assistant.
8. Add Adax Gen 3 Local from Settings → Devices & services.

## Setup

1. Put the heater into pairing mode by holding OK until the blue LED blinks.
2. Make sure Home Assistant is within Bluetooth range.
3. Enter your Wi-Fi SSID and password.

## Status

Experimental. Tested initially against Adax Gen 3 firmware 2.0.3.1 is still pending.
